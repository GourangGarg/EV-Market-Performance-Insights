# EV-Market-Performance-Insights
# Electric Vehicle Market Performance & Insights

## Project Overview
This project analyzes the electric vehicle (EV) market using Tableau Public. The goal is to explore EV sales trends and compare manufacturers, battery types, customer ratings, and driving ranges.

## Project Objectives
- Analyze annual electric vehicle sales trends.
- Compare sales across manufacturers.
- Explore different battery types.
- Examine average customer ratings.
- Compare driving ranges across EV categories.

## Tools and Technologies
- Tableau Public
- CSV Dataset
- GitHub

## Key Visualizations
1. Annual EV Sales Trends
2. Sales by Manufacturer
3. EVs by Battery Type
4. Average Customer Ratings by Manufacturer
5. Average Driving Range by Category
